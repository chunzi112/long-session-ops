# 便签与交接模板

## 会话里的便签（每天更新）

```markdown
# 交接 / 现在的位置

## 现在在哪
- 正在做的事：一句话
- 到了哪一步：一句话
- 相关文件：路径

## 下一步
- 明天第一件事：
- 排好的任务：时间 + 做什么

## 昨天卡在哪
- 卡点：
- 试过什么、为什么不行：

## 别忘的
- 他特意说过的：
- 踩过的坑（简短）：
```

## 换会话时的交接（一次）

把便签 + 上次压缩摘要 + 最近 20 条他说的话，一起贴进新会话。工具见 `tools/quanya-摘要.cjs`。

## 写的时候别做这几件事

- 别写「今天聊了很多」这种等于没写的话
- 别把结论写成过程（要的是「现在在哪」，不是「我们怎么走到这」）
- 别在便签里贴代码，贴路径
- 拿不准的留着，别为了干净删掉
