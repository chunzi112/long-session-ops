# 踩坑清单

都是真踩过的，按「现象 → 原因 → 怎么办」写。

## 1. 配置文件写坏了，宿主起不来
- 现象：重启后起不来，日志说格式不对
- 原因：用脚本读改写，编码带了 BOM，或者转义被吞
- 怎么办：改前备份；写完读前三个字节（`7B 0D 0A` 才对），或者显式用无 BOM 的 UTF-8 写

## 2. 插件写会话日志，把历史搞到打不开
- 现象：重启后整段历史报格式错误，永久打不开
- 原因：插件往会话日志里写自定义事件
- 怎么办：**会写会话日志的插件，不要在唯一一条长会话上试**；先在别的工作区试

## 3. 两个记忆插件同名工具，静默少一半
- 现象：装了新插件，工具只挂上一半，报 unknown tool
- 原因：两个插件注册了同名工具
- 怎么办：二选一；或者只留其中一个的功能

## 4. 渲染视频去下无头浏览器，卡在下载
- 现象：渲染一直没动静，进程 CPU 是 0
- 原因：工具默认去下载 headless 壳，网络不通就干等
- 怎么办：指定系统里已有的 Chrome/Edge 可执行文件

## 5. 合音频合出静音
- 现象：视频有画面没声音，音轨码率只有 2 kb/s
- 原因：输入文件自带一条静音轨，默认选到了它
- 怎么办：显式指定轨道（`-map 0:v:0 -map 1:a:0`），合完用 volumedetect 验一遍

## 6. 语音合成服务会「假死」
- 现象：第一段十几秒，第二段直接卡住
- 原因：本地 TTS 跑久了会卡
- 怎么办：每段单独生成、失败就重启服务；启动后用真实请求探活，别只看端口通
