# 实测账

数据来自一条跑了 7800 多轮、压过 9 次的真实会话（128k 级别窗口，2026 年 11 月）。

## 压缩本身

| 项 | 实测 |
|---|---|
| 一次压缩读进去 | 25 万～42 万 token（最后一次最大 42.6 万） |
| 一次压缩的花费 | ¥0.2～0.4 |
| 九次合计 | 不到 ¥3 |
| 输出上限 | 65536 token（摘要本身远小于此） |

结论：压缩本身不是大头，**每轮重读历史才是**。

## 什么时候开始变钝

- 7800 轮左右开始出现：反复确认已经确认过的事、引用错前面的结论
- 最像「故障」的症状：把脑子里的话漏进正文里发出去
- 压得太晚（一次砍一大块）之后，症状会集中出现

## 钱的量级

- 一天重度聊天：约 ¥10
- 只说话不干活：约 ¥3

## 别学这套的情况

- 你能痛快开新会话，且不在乎换人 —— 那就别学，换会话更便宜也更干净
